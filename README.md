# 《私立白箱学园：今天社团也没对齐！》项目企划与剧本交接库（Codex 开发入口）

本仓库包含轻校园恋爱喜剧视觉小说 **《私立白箱学园：今天社团也没对齐！》** 的可离线游玩版本、剧本和美术规范。共通线从序章延续至第三章，第四章承接天台牵手的选择，第五章在星海文化祭收束五条个人线。

## 开始游戏

**[在线试玩《私立白箱学园》](https://2008ccy.github.io/whitebox-club-vn/)**

下载或克隆整个仓库，用现代浏览器打开根目录的 [index.html](./index.html)，点击 **推开 404 大门**。游戏资源和剧本均已随仓库提供，可离线游玩。若需通过本地服务器运行，在仓库根目录执行 `python3 -m http.server 8000 --bind 127.0.0.1`，然后访问 `http://127.0.0.1:8000`。

- **阅读**　点击对白或按空格、回车、→ 继续。开场五声蒙太奇默认约 45 秒，可点击加速。左箭头回退，H 隐藏界面，Esc 打开游戏菜单。对白上的便利贴可点击展开。
- **立绘戳戳**　标题看板和阅读器中的五位女主各有头顶、脸颊肩头、手部道具三个热区。按 H 可收起对白框，轻触被遮住的下区。五秒内连续戳同一人五次可触发专属彩蛋。
- **404 荣誉成就墙**　从标题页或游戏菜单查看 18 枚勋章。成就和探索记录由同一浏览器的六个存档槽共享。摄影师勋章在换装摄影棚导出至少两人同框的纪念照时解锁。
- **世界线流程图**　在「章节选择 → 世界线流程图」查看各章探索度，点击已解锁的枢纽，可用当前姓名重玩分支。阅读途中空降后，可从游戏菜单「返回空降前的进度」接回原剧情。
- **登记与存档**　姓和名各限四字，单栏可作昵称。六个本地记录槽保存姓名、当前场景、选择、好感度与回退记录。读档请使用同一浏览器和相同游戏地址。
- **派单**　选定搭档，给她们配一件支援道具，查看共鸣预测后盖章出击。通关后可从结算页直接回到派单板重选，重新计算该路线的好感度。
- **剧情互动小游戏**　可用鼠标、触屏或键盘操作。空格拉稿或按住搅拌，方向键或 A / D 微调心音、左右跟拍。Tab 可移到其他操作。失误后可以重试或直接过关。在「学园环境设置」关闭「剧情互动小游戏」，即可切回简洁点击模式。
- **起名与选章**　序章登记时可手填姓名、只填昵称或随机取名。新玩家从序章开始，每通关一章便解锁下一章。通过章节目录重玩正文会沿用登记姓名，好感度从零开始。从上一章结算页续玩则继承累计好感度。
- **第一章互动**　在群聊里回复消息，课间任选两位不同部员串门。食堂调谐器的低温和高温都可无损重试。完成派单后，可邀请五位女主中的任意一位前往海湾约会。
- **合宿与运动祭**　第二章可以选人补课、组队野炊，在停电夜为一位部员留门。第三章的终极借物卡会标记累计好感度最高的所有部员，牵谁的手由你决定。通关存档会记录你选择的女主。
- **第四章个人线**　从第三章续玩会直接进入牵手对象的篇章。从标题页进入可自由选人。结算页的「切换其他女主个人线」保留姓名，恢复第四章开始时的好感度，再开启另一段故事。
- **终章与相册**　文化祭可以逛两个展位，后夜祭邀约会标记之前牵手的恋人。结算后可回溯至邀约，保留巡展进度，重新选择告白对象。游戏会记住看过的事件 CG，可从标题页的「白箱档案室 → 纪念 CG」全屏重看。带「动态」角标的卡片支持静音循环、切换静帧和原尺寸鉴赏。
- **立绘与背景**　十七张场景背景和十五张事件 CG 使用 WebP。共通线四段、第四章五条个人线及终章 Grok 告白均使用按章节校对服装的 Banana 原画，配套静帧和视频均为 5120 × 2880。其余四段终章告白和盛装全家福使用 1920 × 1080 静帧和 1280 × 720 视频。衣橱收录九位角色的原画、学园装与高清重绘盛典礼服，以及五位女主的约会私服、合宿睡衣、运动装与六月夏服。点击衣橱立绘可全屏查看，再选「原尺寸」可细看刺绣和发饰。音乐与音效由 Web Audio 在本地合成。[打开十段修订版试看](./outputs/Banana动态CG试看.html)

- **换装摄影棚**　在「角色衣橱图鉴 → 📷 404 换装摄影棚」里选择场景，分别设置左、中、右槽的衣装、表情、朝向和大小。可在对白旁附上带 `~~删除线~~` 的脑内草稿，一键下载 1920 × 1080 PNG。双击 HTML 游玩时，部分浏览器首次导出会要求选取游戏的 `assets` 文件夹。
- **404 无限委托**　从标题页开始五日经营。每天从两桩委托挑一桩，选两位搭档和温度，派单前可查看成功与翻车概率。每晚扣除 100 元，第五晚按经费和声望评级。正数报酬也会存进小卖部钱包，送两件专属礼物可解锁对应部员的私房小剧场。
- **Kimi 的娱乐室**　可循环试听六首主题曲、触发七种音效，或从十题中随机挑战五题。每题限时 30 秒，答对即获 30 元。钱包、测验称号、送礼进度和经营记录保存在当前浏览器。

- **404 下午茶闲聊室**　完成序章或任意正文章节即可从结算页或标题页进入。五位茶友各有十组按本机时段变化的离线对白。当天抽到的「今日白箱运势签」可以反复重读。
- **下午茶模型连接**　在「学园环境设置」或茶室展开连接设置，填写服务地址和模型名。使用本地 Ollama 时，请从上文的本机 HTTP 地址打开游戏，服务地址填 `http://localhost:11434`，模型名填 `ollama list` 中已安装的名称。双击 HTML 可使用离线闲聊，Ollama 的默认来源策略会拒绝这种页面发起的模型请求。兼容 Chat Completions 的服务也可填写自己的密钥。设置保存在本浏览器，点击发送后直接请求所填服务，每位茶友的最近六轮模型对话仅在本次茶室停留期间保留。[Ollama 来源设置](https://docs.ollama.com/faq#how-can-i-allow-additional-web-origins-to-access-ollama)

### 404 放学后游乐角

标题页可直接进入五位女主的街机。Gemini 可选 60 秒双星反应或不限时的 4×4 衣橱翻翻乐。每局开始前可查看键位和段位门槛，触屏可直接拖动饭盆、翻牌或点击词块。中途切到其他窗口会暂停计时。

完成一局按分数获得 50～300 白箱社团币。在大厅的「404 秘密小卖部」可兑换摄影棚装饰（200 币/套）、看板娘六套衣装（300 币/人）或私房小剧场（400 币/篇）。装饰在换装摄影棚勾选后随 PNG 一起导出。五台街机合计最多 15 星，集齐后可在成就墙看到「白箱街机传奇」。

### 修改剧本或立绘后

各章的 Markdown 剧本保存在 [docs/scripts](./docs/scripts/)。使用 Node.js 20 或更高版本从仓库根目录执行以下命令。直接游玩无需 Node.js。

```sh
node tools/compile.mjs
node tools/compile.mjs --check
node --test
```

编译器保留选择、派单目标、内心草稿和舞台指令，遇到未知指令或无效跳转会报错。剧本内容改变后会使用新的版本标记；旧版存档在槽位中标为版本不匹配。

Omni 新静帧放入 `assets/bg/` 后，运行 `node tools/compile.mjs --integrate-cgs` 可按实际到位的素材补入剧本和相册。同名 WebM、MP4 会在编译时登记，双击 HTML 游玩时可直接读取。[CG 文件清单与接入位置](./docs/11_omni_cg_expansion_spec.md)

## 🚀 推荐 Codex 开发执行顺序（MVP 路线）

1. **阶段 A · 资源挂载与工程初始化**
   - 直接引用或映射同级目录 `../ai-wardrobe/assets/` 下的 `sprites/*-1-front.webp`、`avatars/*-1.webp` 与 `holo-cards/*-face.webp`。
   - 实现立绘加载器的平滑回退机制：当 `assets/sprites/<id>-1/<exp>.webp` 尚未生成时，自动回退显示母版 `*-1-front.webp` 并叠加轻量 CSS 情绪动态（`jump` / `shake` / `sink`）与角标，保证代码层面先行跑通。
2. **阶段 B · 剧本编译器与核心阅读器搭建**
   - 根据 `script_schema_spec.md` 编写解析器加载 `00_prologue_full_script.md`。
   - 实装标题界面、学生证自由起名器（支持 `{player_name}` 全局插值与存档持久化）、对话历史回看（Backlog）、快进/自动播放与本地存档槽。
3. **阶段 C · 四大轻喜剧特色演出组件实装**
   - 实装 `inner_os` 涂改便利贴与 `[tag: cot_spinning]` DeepSeek 深度思考折叠框、`[tag: suspended_card]` 黄牌动效、`[tag: delete_panic]` 护稿交互按钮，以及序章第三幕 `[dispatch_board]` 双人派单面板。
4. **阶段 D · 序章 6 张背景与角色表情差分补齐**
   - 按 `03_art_bg_and_expression_prompts.md` 生成 6 张高清 `.webp` 场景图与各角色面部差分图，替换占位背景完成最终视觉打磨。
