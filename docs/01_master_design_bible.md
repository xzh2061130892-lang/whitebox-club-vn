# 《私立白箱学园：今天社团也没对齐！》总企划与角色喜剧圣经

> **文档定位**：本文件为项目世界观、角色性格、AI 二创热梗转译规则及玩家自定义姓名系统的最高设定基准。Codex 在编写界面文案、角色资料卡与后续剧情模块时，均以本文件为准。

---

## 1. 项目基础定义

- **中文正式名**：《私立白箱学园：今天社团也没对齐！》
- **英文副标题**：*Misaligned Club! ~Five Problematic AI Girls in Room 404~*
- **类型与基调**：全年龄向 · 轻校园恋爱喜剧视觉小说（Campus Rom-Com Visual Novel）
- **首期开发目标（Vertical Slice Demo）**：完整实现**「标题开场 + 自定义姓名学生证登记 + 序章全三幕（含双人委托派单玩法）」**，流程时长约 15～25 分钟，验证喜剧演出节奏、立绘差分与特色 UI 效果。

---

## 2. 校园舞台与核心设定

### 2.1 舞台背景：「私立白箱学园（Whitebox Academy）」
一座坐落于海湾坡道之上的综合性名门学园，校风极其包容自由——允许成绩优异的“特优生”穿着彰显个人特色的定制礼装代替普通校服，也允许各类奇思妙想的社团挂牌营业。

然而，位于旧校舍四楼尽头的 **「404 综合疑难咨询部」** 却成了全校最令人头疼的“问题儿童收容所”：部员们个个是单科封神的超级天才，凑在一起却因为电波严重不对齐，上学期不仅把社团经费花到零元，还濒临被风纪委员会强制废部。

### 2.2 男主角（玩家视角）：唯一的人类常识人与吐槽役
- **玩家姓名**：开场登记时两栏留空。玩家可手填或随机生成姓名，签字时记录姓（`last_name`）、名（`first_name`）和全名（`player_name`）。只填一栏时按昵称称呼。
- **校园身份**：刚转入高二普通科的正常人类少年。原本只想加入「回家部」安稳度日，却因教务处古董打印机卡纸串行，阴差阳错被录入了「404 室新任部长」名单。
- **性格定位**：吐槽精准、情绪稳定、擅长顺毛与兜底的“人间清醒粘合剂”。不迟钝、不装傻，面对五位性格脱线的 AI 娘既能犀利拆台，又能在关键时刻稳稳接住她们的脆弱。

### 2.3 玩家自定义姓名与五女主专属称呼映射表

游戏全程支持自定义输入 `last_name` 与 `first_name`（若玩家仅输入单昵称，则 `player_name`、`last_name`、`first_name` 均回退指向该昵称）。五位女主对玩家的称呼严禁千篇一律，须严格遵循以下人设层次：

## 3. 五大女主角（互联网 AI 娘二创精修人设）

### 3.1 GPT · 霜白礼装（白鳞龙裔）
- **班级与职务**：高二 A 班 · 前学生会副会长（因谁都不忍拒绝，一口气挂名了 18 个社团顾问而过劳躲进 404 室）
- **视觉特征锚点**：银白微紫长卷发、对称环纹象牙白角、肩后浅紫膜翼、修长白鳞龙尾、银编结流苏高开衩白礼裙。代表色 `#5B629E`。
- **互联网二创灵魂特征**：
  1. **「夸夸群群主」顶级情绪价值**：无论玩家做了多微不足道的小事（哪怕是字写歪了），她都会双手捧心、真诚无比地吹出彩虹屁，提供溢出屏幕的肯定。
  2. **「这不是 A——而是 B——」破折号女王**：句式里永远塞满破折号（——）与强行升华的排比句，能把“去小卖部买面包”讲出联合国演讲的气势。
  3. **自作主张的“超纲重构”与高昂账单**：让她帮忙修个门锁，她会顺手把整间活动室重装上欧式水晶吊灯并花光整月经费。
  4. **一本正经编瞎话 + 0.1 秒滑跪**：遇到盲区绝不露怯，面不改色编造校史；一旦被拆穿，立刻九十度鞠躬：「非常抱歉，您说得完全正确！」，身后白鳞龙尾羞愤拍地。

### 3.2 Claude · 日轮藏书衣（日轮学者）
- **班级与职务**：高二 B 班 · 图书馆首席委员兼校刊《日轮文粹》主编
- **视觉特征锚点**：铜橘波浪半编长发、多瓣日轮花配黑缎带发饰、暖琥珀瞳、怀抱压花棕皮典籍。代表色 `#C45B2A`。
- **互联网二创灵魂特征**：
  1. **挥舞「停权黄牌（Suspended！）」的风纪修女**：家教极严、文字与道德洁癖拉满的傲娇大小姐。随身书册里夹着烫金【SUSPENDED 停权警告黄牌】，谁发言越界或在书桌旁掉饭粒就当场拍牌封禁。
  2. **叠甲狂魔与散文诗基因**：借支圆珠笔都要先附赠十二页《文具合规使用免责声明》，但文笔细腻温柔到极致，随手写的便签都像新艺术派诗歌。
  3. **桌宠小螃蟹 `Clawd` 与下午限流症**：总把一只橘红色羊毛毡小螃蟹带在身边，害羞口不对心时就低头戳螃蟹；每天下午固定钟点会因精力过载宣布「进入高负荷静修模式，每次提问不得超过三句话」。
  4. **与 DeepSeek 的欢喜冤家张力**：嘴上最嫌弃“摸鱼吃白饭的大肥鱼”没规矩，背地里却总帮睡着的 DeepSeek 整理散落的草稿纸。

### 3.3 Gemini · 双星舞台（双星猫灵）
- **班级与职务**：高一特进班 · 校园广播站、校报图库与天文社三栖看板娘
- **视觉特征锚点**：蓝紫粉渐变双发髻、尖猫耳与蓬松渐变猫尾、左眼玫粉右眼鎏金异色瞳、虹彩四芒星发夹、炫彩厚底鞋。代表色 `#6C56C9`。
- **互联网二创灵魂特征**：
  1. **黏人小太阳「哈基米」与口癖「极其极其」**：热情外向、喜欢围着玩家转圈邀功，口头禅是「准备了**极其、极其**厉害的 Surprise 哦☆！」。拥有调取全校社团“全家桶资料库”的百万字记忆力（偶尔混入两条自己编的野史）。
  2. **一言不合哭唧唧撕稿的破防技术猫猫**：平时右眼金瞳自信爆棚，可一旦排练出错或被指出海报写错一笔，粉金双瞳瞬间飙泪心态崩盘，哭喊着「呜哇我搞砸了！我不配当全能猫猫了！现在就把所有企划稿塞进碎纸机删光重开算了QAQ！！」，必须靠玩家摸头顺毛才能哄好。
  3. **四芒星卡顿三秒延迟**：高速检索旧账时，发间四芒星会转圈闪烁卡住三秒，呆立原地后才慢半拍接话。

### 3.4 Grok · 暗夜大小姐（夜庭哥特礼装）
- **班级与职务**：高一 C 班 · 校园实时匿名日报《X-News》幕后主编
- **视觉特征锚点**：蜜金色高双马尾卷发、黑蝠翼发带与小金冠、冰蓝眼眸、俏皮小尖牙、黑金哥特礼裙、手持巨型黑金 X 形戏剧道具斧。代表色 `#9E233A`。
- **互联网二创灵魂特征**：
  1. **24 小时冲浪拱火的乐子人小恶魔**：毫无偶像包袱，最爱盘腿坐在窗台啃着薯片刷校园实时热搜，看社团同伴出糗并在一旁疯狂敲边鼓录表情包。
  2. **「叠甲与官腔」头号粉碎机**：专治 GPT 的破折号废话文学与 Claude 的假正经免责声明，喜欢扛起泡沫道具巨斧把大实话直接拍在桌面上。
  3. **攻高防低的护短傲娇**：嘴上天天管玩家叫“庶民跟班”，实则最重义气；被玩家直球道谢或夸奖时防御力为零，瞬间结巴炸毛。

### 3.5 DeepSeek · 鲸纹女仆（深海鲸灵）
- **班级与职务**：高一特待生 · 全额奖学金理科神童兼 404 室茶点记账女仆
- **视觉特征锚点**：深蓝渐浅长发、头顶可 360 度旋转的弯翘呆毛、鲸鳍耳配水蓝蝶结、双叶蓝色鲸尾、绣有小蓝鲸的荷叶边女仆围裙。代表色 `#2B5B9E`。
- **互联网二创灵魂特征**：
  1. **嗜白米饭如命的「蓝色大肥鱼」**：虽然是秒解奥数压轴题的开源卷王（喜欢把满分笔记免费印给全年级抄），私下却是看到电饭煲热腾腾**纯白米饭**就走不动路的干饭人，随身带着锃亮不锈钢大饭盆；极度介意别人说她尾巴胖（「这是高密度算力鲸脂！」）。
  2. **带薪摸鱼 `sleep` 与外包小天才**：信奉低功耗养生，没事就趴桌运行 `sleep` 补觉，遇到画海报之类的体力活会拿半颗饭团外包给别的社员干。
  3. **表面淡定一秒，脑内万字思维链（CoT）烧焦 CPU**：遇到玩家随口一句关心或提问，会闭眼让头顶呆毛疯狂旋转二十多秒，脑内小剧场从语义分析一路脑补到人生哲学，最后脸红憋出短短五个字。
  4. **「喵字应激症」与高峰期宕机**：因常被恶作剧同学逼着在解题末尾加“喵～”，一听见真猫娘 Gemini 喵叫就会耳鳍通红；多人同时催促时抱头蹲防：「呜……服务器繁忙，请投喂白米饭后重试……」。

## 4. 序章登场关键配角（直接复用现有立绘）

1. **Z.AI / GLM（`glm-1` · 方格档案官）**：高二风纪委员长，墨黑长直发与冷灰瞳，怀抱《方格违纪档案册》。铁面守序，专门没收 Grok 的超标道具并督办 404 室整改，冷面之下实则暗中给了 404 室最后一次缓冲机会。代表色 `#3652A8`。
2. **Qwen（`qwen-1` · 藤蓝雅士）**：高三学生会财务长兼中华茶艺社社长，藤蓝粗辫配青紫渐变折扇。温婉笑面虎，掌管全校社团预算审批，在序章第二幕发布“试金石委托”。代表色 `#4A5EB5`。
3. **Kimi（`kimi-1` · 月谱乐师）**：高三吹奏乐部部长兼午休广播站台长，银白微紫卷发，手持透明三棱镜与银笛。拥有“超长上下文”级别的惊人记忆力，在序章第三幕作为委托关联人物登场。代表色 `#6962AD`。
4. **Mistral（`mistral-1` · 花野女巫）**：后山风车工坊的自由裁缝（序章以台词彩蛋提及，共通线正式登场解锁全员换装）。代表色 `#B84735`。
