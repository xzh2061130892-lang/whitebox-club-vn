### 2.3 功能三：GLM 的世界线流程图（Visual Flowchart）

- **呈现形式**：在【章节选择】对话框中增加标签页切换：`[章节目录]` | `[▦ 世界线流程图（探索度 XX%）]`。
- **自动追踪**：每当 `engine.js` 经过任意 `label`（以及 `dispatch_board` / `free_roam_hub` / `temp_tuner` 选过的选项），自动将其 `storyId + ':' + label` 记入全局 `localStorage` 集合 `whitebox.404.seenLabels`。
- **界面交互**：
  - 按「序章 → 第一章 → 第二章 → 第三章 → 第四章五线 → 第五章五结局」纵向排列节点树，已探索分支高亮显示中文名（如 `✓ 风纪修女与干饭肥鱼`、`✓ Grok 散发睡衣夜话`），未探索分支灰显为 `？ 未探索分支`。
  - 点击任意**已解锁章节枢纽节点**（如 `第一幕自由串门`、`第三幕双人派单板`、`周六私服约会选择`、`深夜留门选择`、`后夜祭告白邀约`），直接带着玩家当前姓名一键空降该节点，丝滑补完 100% 全剧情！

## 三、 P1 级扩展娱乐玩法设计（大幅延长通关后耐玩时长）

### 3.1 功能四：404 自由换装摄影棚（Photo Studio · 同人剧照生成器）

将现有仅能静态看原画图的【角色衣橱图鉴】，升级为三大分页：**`[原画设定集]` | `[纪念 CG 相册]` | `[📷 404 换装摄影棚]`**！

- **摄影棚核心面板**：
  1. **场景选择器**：自由切换游戏内全部 **16 张 16:9 高清场景背景**（404 昼/夕、食堂、温室、海湾水族馆、海景木屋昼/夜、操场、紫阳花雨坡、白玉钟楼、钟表阁楼、星海广场等）。
  2. **三槽位角色摆放（左 / 中 / 右）**：每个槽位可独立选择：
     - **角色**：无 / GPT / Claude / Gemini / Grok / DeepSeek / GLM / Qwen / Kimi / Mistral
     - **衣装**：自动列出该角色已拥有的全部服装（五女主各 6 套：`原设礼装` / `周末私服` / `合宿睡衣` / `春日运动服` / `六月夏服` / `盛典礼服`；四配角各 2 套：`原设` / `盛装`）！
     - **表情**：`normal / happy / blush / shock / smug / panicked / thinking / gentle`
     - **微调**：水平翻转（`flipX`）+ 缩放滑块（`80%～120%`）。
  3. **自定义同人对话气泡 & 便利贴**：玩家可输入任意发言人名称、一句搞笑台词，甚至勾上【附带黄色脑内草稿便利贴】写一句带 `~~删除线~~` 的吐槽！
  4. **一键拍立得导出（Canvas 合成）**：点击 `📷 导出纪念照 (.png)`，在前端将背景、角色立绘、可选的复古相框与自定义对话框/便利贴合成为 `1920×1080` 高清 PNG 下载，天然激发玩家二创与分享欲！
