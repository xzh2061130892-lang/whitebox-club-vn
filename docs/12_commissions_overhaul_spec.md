# 《私立白箱学园：今天社团也没对齐！》「404 无限委托」重制设计规范

> **定位**：将原本“二选一 + 盲抽概率 + 出单行字”的静态填表玩法，彻底重制为 **【校园轻喜剧调度经营 × 现场突发实况救场 × 轻肉鸽设施构筑】** 的高重玩度策略小游戏（单轮 5 日约 3~5 分钟）。
> **美术与技术约束**：**100% 复用现有资产**（5 主角 + 4 配角现有多表情立绘/头像 + 16 张校园实景 BG + 现有音效），**零新美术负担**，且**完全向下兼容**现有 `whitebox.404.activities.v1` 存档中的钱包 (`wallet`)、小卖部亲密度 (`affection`) 与默契测验 (`quiz`) 数据。

## 二、核心玩法闭环（单日三段式节奏）

每一天由三个清晰、爽快、无冗长等待的阶段组成：

```text
[阶段 1 · 晨间派单桌]
  查看今日校园风向 → 从 3 桩委托选 1 桩（可消耗刷新次数换单）
  → 盯住精力槽选 2 名部员（实时点亮「双人羁绊词条」）→ 设温度 (0.1 / 0.7 / 1.6) → 盖章派单！
          │
          ▼
[阶段 2 · 现场实况连线（核心爽点！）]
  切换至委托对应校园场景图，双人立绘上场，进度条推进至 ~55% 触发【前线突发危机！】
  → 玩家从 3~4 个临场指令中择一应对：
     ① 稳妥兜底项（低风险稳步推进）
     ② 冒险整活项（高收益/高翻车，受温度与风向加成）
     ③ 角色 / 双人羁绊专属特解（队伍满足条件时金框点亮，零风险直冲大成功！）
     ④ 背包道具 / 4 位学园外援一键救场（消耗品，逆天改命！）
  → 进度条冲刺结算：SSR 超级大成功 / 大成功 / 顺利完成 / 爆笑翻车（带对应表情切换与专属吐槽）
          │
          ▼
[阶段 3 · 晚间结账 & 404 室整备采购]
  扣除当日固定支出（默认 100 元，可被设施/羁绊减免）→ 未出勤部员自动摸鱼回血 (+2 精力)
  → 逛「晚间采购台」：买设施滚雪球 / 囤救场道具 / 签配角外援 / 给红温部员买星冰乐回血
```

## 三、核心系统与数值机制规范

### 1. 部员精力槽 & 状态系统（驱动轮换与经营取舍）
每位部员拥有 **3 格精力 (`stamina: 0..3`)**，开局全员满格 (`3/3`)：
- **出勤消耗**：每完成 1 桩委托，上场的两名部员各 `-1` 精力。
- **留室休息恢复**：当天未出勤的部员在晚间自动 `+2` 精力（上限 3），并在晚间简报附一句萌系摸鱼状态（例：`DeepSeek 靠着电饭煲打盹，精力 +2`、`Claude 给小螃蟹梳毛，精力 +2`）。
- **状态修正**：
  - `3 格（元气满载）`：初始完成度 `+5%`。
  - `1~2 格（正常营业）`：无惩罚。
  - `0 格（过劳红温 · 头像泛红标红温）`：仍允许硬派上场！但风险值 `+22%`、初始完成度 `-10%`，触发专属吐槽（如 GPT 狂打破折号、Claude 限流黑屏、DeepSeek 边打瞌睡边算账）；**但若在过劳状态下奇迹拿大成功，额外奖励 +80 元“燃尽加班补贴”！**

### 4. 输出温度 (`T = 0.1 / 0.7 / 1.6`) 战术重构
不再只是改两个隐藏概率数字，而是改变**现场进度条的初始风险、收益倍率与可选指令**：
- **`0.1 稳健对齐`**：基础风险 `-12%`，完成度波动小；收益倍率 `×0.9`；锁定高危整活项（适合保底防破产、过劳救场）。
- **`0.7 校园均衡`**：标准风险与完成度；收益倍率 `×1.0`；全部常规与特解选项开放。
- **`1.6 放飞过载`**：基础风险 `+18%`；大成功与超级大成功收益 **`×1.45`**、声望额外 `+1`；解锁**专属紫红色「1.6 放飞赌狗选项」**，且触发爆笑翻车时额外掉落 `+40 元` “校园话题热搜安慰奖”！

### 5. 现场实况判定模型（直观透明，爽感拉满！）
- 派单出发时计算 **初始基础值**：
  - `progress`（初始完成度，基准 `45%`）：每个匹配的专长标签 `+12%`，最佳搭档组合额外 `+10%`，满精力 `+5%`，过劳 `-10%`，再加上设施与风向加成（展示为从 `0%` 流畅动画涨到初始值，随后触发突发！）。
  - `risk`（风险值，基准 `20%`）：受温度（`-12% / 0% / +18%`）、过劳（`+22%`）、羁绊与设施增减影响，钳制在 `5% ~ 85%`。
- **突发干预结算**：
  - 玩家选择干预策略后，系统执行选项效果（加减 `progress` / `risk` 或直接强制判定），然后进行一次**带视觉冲击的进度条冲刺演出**（`progress` 最终值 vs 门槛，叠加一次 `risk` 检定，且玩家若使用 `星光急救贴纸` / `空白黄牌` / `外援` 可直接改写判定！）：
    - **`SSR 传说神单`（仅当 `progress >= 115%` 且未翻车）**：报酬 `bonus × 1.35`、声望 `+4`，播放 `se_rice_ding` + 金色星屑特效！
    - **`大成功`（`progress >= 85%` 且未翻车）**：报酬 `bonus`、声望 `+3`。
    - **`顺利完成`（`progress >= 55%` 且未翻车）**：报酬 `基础报酬 (150~210)`、声望 `+1`，展示该委托专属的顺利完成反馈（告别千篇一律的复读机！）。
    - **`爆笑翻车`（`progress < 55%` 或触发高风险暴雷）**：报酬 `loss`（可能为负或少量补偿）、声望 `-1`（`GPT×Grok` 免扣），播放 `se_shredder_jam`，解锁对应**爆笑翻车剪报**！
