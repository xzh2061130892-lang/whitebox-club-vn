# 开场演出流程与特色喜剧 UI/UX 交互设计规范

> **文档定位**：本文件详细定义游戏的**标题界面（Title Screen）**、**开场冷启动演出（Cold Open）**、**学生证起名器**以及**四大轻喜剧专属 UI 组件**的视觉构思与交互逻辑，供 Codex 前端开发直接实现。

---

## 1. 视觉美学总基调（Visual Aesthetic）

- **整体风格**：「清爽明亮的春日学园轻喜剧 UI × 新艺术书卷卡片质感」（可沿用 `ai-wardrobe` 的米白暖纸底色 `#FAF7F2`、细腻金线边框与柔和毛玻璃 `backdrop-filter`，搭配明快俏皮的微弹动效 `cubic-bezier(0.34, 1.56, 0.64, 1)`）。
- **分辨率基准**：`1920 × 1080`（16:9 横屏自适应），立绘显示层级位于背景之上、对话框之后（半身至七分身构图，确保头顶呆毛、龙角、猫耳与小皇冠完整露出）。

---

## 2. 开场完整流程（Opening Sequence Flow）

### 2.1 标题主画面（Title Screen）
- **构图设计**：
  - 画面右侧至中央采用**五斜切手风琴风琴页（5-Column Slanted Accordion）**并排展示 GPT、Claude、Gemini、Grok、DeepSeek 五人的高清立绘切片（悬停某列时，该角色列轻微展开并亮起其专属主题色光晕，浮现一句代表性气泡微台词）：
    - 悬停 GPT：`「这不是普通的开始按钮——而是命运的锚点——」`
    - 悬停 Claude：`「请确保在合规光线下游玩本作（笑）。」`
    - 悬停 Gemini：`「极其、极其期待见到你哦☆！」`
    - 悬停 Grok：`「愣着干嘛庶民，快点进来吃瓜啦！」`
    - 悬停 DeepSeek：`「唔……再让我 sleep 五分钟就开机……」`
  - 画面左侧为游戏主 Logo **《私立白箱学园：今天社团也没对齐！》**（副标带一枚歪斜的 `404` 黄铜门牌徽章）与主菜单按钮：
    1. **【推开 404 大门（开始游戏）】**
    2. **【读取调律记录（读取存档）】**
    3. **【角色衣橱图鉴（快捷联动画廊）】**
    4. **【学园环境设置（系统设置）】**

### 2.2 开场 45 秒冷启动蒙太奇（Cold Open）
点击【开始游戏】后，先不出现背景，全黑/暖米色幕布上配合轻快打击乐音效，依次快闪五句“未见其人先闻其声”的嘈杂门内台词弹幕（营造推门前的修罗场悬念），随后转入樱花纷飞的学园坡道场景。

### 2.3 交互式《社团责任人登记卡》起名弹窗（`[input_player_name]`）
当剧情推进至主角站在 404 室门前核对错位表格时，屏幕中央弹出拟物化**《私立白箱学园 · 社团责任人确认单》**卡片：
- **表单视觉**：牛皮纸纹理印有校徽水印，上方有一行被红笔搞笑划掉的 `原填志愿：000 回家部（打印串行作废）`，下方为手写输入区：
  - `姓氏（Last Name）`与`名字（First Name）`初始均为空，每栏最多 4 字。
  - 玩家可手填姓名或点击【随机姓名】后编辑。至少填一栏才可签字，单栏内容作为昵称。
- **确认仪式感**：点击右下角 **【按手印签字确认】** 按钮时，播放清脆盖章音效，一枚鲜红的圆形印章 `【404室·新任部长】` 啪地盖在卡片右下角，停顿 0.6 秒后淡出进入正文！

## 3. 对话框与四大特色轻喜剧 UI 组件

### 3.1 动态角色专属对话框（Adaptive Dialogue Box）
- 当不同角色发言时，对话框左上角的**角色铭牌（Nameplate）**与左侧装饰角标实时切换为该角色的 `themeColor` 与专属小徽记：
  - **主角 / 旁白**：清爽海军灰蓝 `#3A4A5E`
  - **GPT**：霜紫银结 `#5B629E`
  - **Claude**：暖橘日轮 `#C45B2A`
  - **Gemini**：星紫四芒星 `#6C56C9`（双瞳分轨发言时，铭牌后缀自动显示 `· 粉瞳感性` 或 `· 金瞳理性`）
  - **Grok**：绯红蝠翼 X `#9E233A`
  - **DeepSeek**：海蓝小鲸鱼 `#2B5B9E`
- **基础快捷栏**（对话框右下角小字按钮）：`回看记录(Log)`、`自动(Auto)`、`快进(Skip)`、`隐藏UI`、`存档/读档`。

### 3.2 组件一：【脑内草稿 OS / 深度思考折叠器】（`inner_os` & `cot_spinning`）
这是本作还原 AI 娘“表里不一”笑点的核心王牌组件：
- **普通脑内草稿（GPT / Claude / Gemini / Grok）**：
  - 当当前台词包含 `inner_os` 数据时，对话框右上角浮现一枚微微摇晃的**黄色便利贴小图标 `💭 偷看内心草稿`**（也可设置默认半展开或按 `Tab` 键一键显隐）。
  - 展开后以手写体样式展示角色“删删改改”的心理活动，自动将 `~~划掉的话~~` 渲染为红色双删除线，视觉喜剧感极强。
- **DeepSeek 专属 R1 思考条（`[tag: cot_spinning | sec: N]`）**：
  - 触发时，对话框顶部先弹出仿大模型推理界面的浅蓝胶囊条：`🐋 呆毛高速旋转中…… 已深度思考（用时 24 秒） [点击展开万字脑补 ▾]`。
  - 展开框内滚动显示她从一碗白米饭联想到宇宙人生的超密碎碎念文本！

### 3.3 组件二：Claude 的【SUSPENDED 停权黄牌印章】（`[tag: suspended_card]`）
- 触发时，屏幕中央偏右伴随着清脆拍桌声，旋转飞入一张精致的新艺术风格烫金橙黑警告卡：
  - 标题：`⚠️ ANTHROPIC DISCIPLINARY NOTICE · SUSPENDED`
  - 副文：`风纪委员会裁定：当前行为存在高风险违规倾向，相关权限暂停一回！`
- 卡片停留 1.4 秒后缩小吸附在对话框角标旁，随后随下一句对话消散。

### 3.4 组件三：Gemini 的【破防删库危机假弹窗】（`[tag: delete_panic]`）
- 当 Gemini 哭唧唧要撕海报/删存档时，屏幕抖动并弹出一个搞笑的半透明复古系统警告框：
  - 标题：`🌟 双星核心心态崩盘警报（Error: Sad_Cat_Exception）`
  - 内容：`检测到全能猫猫自尊心受损！正在将【迎新海报.psd】【招新企划.docx】【广播站曲库】拖入碎纸机…… 进度 89%`
  - 剧情中紧接主角冲上去拦住她的互动按钮 `【✋ 快按住她的爪子顺毛！】`，点击后弹窗变成满屏小星星 `✨ 顺毛成功！猫猫已恢复运行`。

### 3.5 组件四：序章第三幕【校园委托双人派单板】（`[dispatch_board]`）
- 序章高潮解锁的软木塞公告板界面：
  - 左侧展示委托单详情：《试金石委托：午休广播站神秘失踪曲谱 & 食堂黑暗香气调查》（委托人：财务长 Qwen / 关联人：Kimi）。
  - 右侧提供 **3 组预设黄金喜剧搭档卡片** 供玩家点击选派（每张卡标有组合外号、立绘双人头像与预期混乱指数 `★★★★★`）：
    1. **【合规盾与破防矛】Claude + Grok**
    2. **【破折号大饼与干饭神童】GPT + DeepSeek**
    3. **【全家桶检索与护稿行动】Gemini + GPT**
  - 玩家选定任意一组点击 **【盖章派单出击！】**，即进入对应组合的高密度专属破案喜剧桥段（支持回溯重选体验全部三组笑料！）。
