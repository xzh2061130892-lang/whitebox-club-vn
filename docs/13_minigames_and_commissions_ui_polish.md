# 《私立白箱学园：今天社团也没对齐！》小游戏与「404 无限委托」UI/界面设计优化规范

> **审查依据**：基于最新实装版本（含新版三段式 `404 无限委托`、`404 放学后游乐角` 5 款街机小游戏、`Kimi 娱乐室`、`剧情互动小游戏`），结合 **桌面端 `1440×810`** 与 **手机竖屏 `390×844`** 实机巡检与截图核验整理。
> **核心目标**：**锁定统一弹窗宽高彻底消除切换游戏时的界面大小跳变**、消除委托界面的“管理后台表单感”、消灭多处单字换行与滚动折页截断、修复游乐角 Grok 侧栏立绘不可见 Bug，让所有小游戏都具备**外框稳如磐石、一屏清晰、色彩语义明确、充满校园轻喜剧桌面质感**的精品 UI 体验。

## 零、全局最高优先 [P0]：锁定弹窗固定宽高，彻底根治切换游戏时的界面大小跳变

### 实测根因定位
当前切换不同游戏或页签时，界面会出现非常难受的**横竖双向剧烈缩放与顶栏上下乱跳**，由三个叠加原因造成：
1. **横向宽度 4 档互相拉扯**（`src/game.css` / `activities.css` / `arcade.css` / `commissions.css`）：
   - 在「404 社团活动室」内：`无限委托` (`1010px`)、`放学后游乐角` (`1010px`) 切去 `Kimi 娱乐室` (`760px`) 或 `下午茶` (`760px`) 时，弹窗骤缩 `250px`；
   - 在「白箱档案室」内：`原画衣橱` (`1000px`) → `纪念 CG` (`760px`) → `换装摄影棚` (`1210px`) → `荣誉成就墙` (`760px`) 连跳 3 档宽度，最大落差 **`450px`**！连鼠标正点着的 `#hub-nav` 按钮都会瞬间横向漂移跑出指针下方。
2. **只设 `max-height` 未锁 `height`，叠加 `<dialog>` 垂直居中导致顶栏上下弹跳**：
   - 例如委托开局页（`~440px`）→ 晨间派单桌（`~736px`）→ 现场连线（`~680px`），或游乐角大厅（`~710px`）→ 规则简报（`~430px`）→ 实际小游戏（`~520–640px`），每切换一步整个弹窗都在屏幕上上下抽搐。
3. **5 款游乐角街机内部 `.arc-machine` 高度各自为政**：实测从 `334px`（破折号）到 `427px`（接白米饭）相差近 `100px`。

### 根治修改方案（“定锚固定窗体 + 标准机框”体系）
1. **两座大枢纽（「404 社团活动室」与「白箱档案室」）统一锁定固定宽高（`.hub-open`）**：
   - 在 `src/game.js` 的 `hubNav(page)` 中，只要当前页属于 `activities` 或 `archives` 任一枢纽，统一给 `#system` 挂载 `.hub-open`（移除由各子页面各自 `add/remove` `commissions-open` / `arcade-open` / `studio-open` / `:has(.wardrobe-layout)` 带来的宽度覆盖冲突）：
     ```css
     #system.hub-open {
       width: min(1080px, 95vw);
       height: min(760px, 92svh);
       max-height: 92svh;
     }
     @media (max-width: 650px) {
       #system.hub-open {
         width: 96vw;
         height: 92svh;
         max-height: 92svh;
       }
     }
     ```
   - 效果：在同一座枢纽内任意切换 4 个馆内 Tab，或在委托各阶段（开局 / 晨间 / 现场 / 回执 / 晚间 / 结算 / 图鉴）、游乐角各页面（大厅 / 简报 / 5 款游戏 / 秘密小卖部）间来回切换时，**外框宽、高与顶栏位置 100% 像素级纹丝不动**！
   - 附带同步稳住「章节选择 / 世界线流程图」弹窗：给 `chapters` 弹窗也锁定统一高度（如 `#system.chapters-open { width: min(820px, 92vw); height: min(680px, 88svh); }`），防止切流程图时突然拉长。
2. **宽定高窗体内的轻量内容页居中铺展（告别底部空洞）**：
   - **换装摄影棚**：在 `1080px` 宽窗下将 `.studio-layout` 调整为 `grid-template-columns: minmax(0, 1.55fr) minmax(280px, 1fr)`，画布与控件依旧一屏无截断；
   - **Kimi 娱乐室**：点唱机 6 首曲目顺势排布为更舒展的 **3×2 网格**，默契十题测验给题目卡片加 `max-width: 780px; width: 100%; margin-inline: auto;` 优雅居中；
   - **纪念 CG 相册 / 荣誉成就墙**：在 `1080px` 下自然展开为 3 列网格，大幅减少滚屏；
   - **委托开局选模式页 / 游乐角规则简报页**：主体内容区在固定高度内采用柔和居中限宽布局（`max-width: 820px; width: 100%; margin-inline: auto;`），视觉均衡大气。
3. **统一游乐角 5 款街机内部舞台高度**：
   - 给 `.arc-machine` 设定统一稳定高度（桌面端 `min-height: clamp(390px, 52svh, 460px)`，移动端保持自然堆叠），左侧 `.arc-play` 居中承托玩法核心区，右侧 `.arc-announcer` 等高撑满——让 5 款小游戏就像在同一台标准复古街机框里切换卡带一样稳重丝滑！

## 一、核心重点：「404 无限委托」UI 重构（从“后台表单”升级为“404 指挥桌”）

### 1. [P0] 压缩“七层套娃顶栏”，实现桌面 `1440×810` 一屏免滚操作
- **实测痛点**（涉及 `src/commissions-ui.js`、`src/commissions.css`、`src/game.css`）：
  - 当前打开委托后，上方连续堆叠：`.dialog-head` (`76.5px`) → `#hub-nav` (`51.7px`) → 子 Tab (`31px`) → `.cm-modes` (`30.2px`) → `.cm-status` (`64.3px`) → `.cm-weather` (`23.6px`) → `.cm-pack` (`17.6px`)，合计吃掉 **`371px`**（超过 `736px` 弹窗一半高度，手机端高达 `474px` / 55%+）！
  - 直接后果：晨间派单桌的 **`盖章派单`**（落在 `y=794px`）和现场实况的 **3 个危机选项卡片**（落在 `y=720..826px`）在桌面端全被底边截断，每一步都要来回滚屏。
- **优化方案**：
  1. **对局中隐藏 `.cm-modes` 模式条**：只在开局选模式屏或结算屏展示 3 个大模式卡片；对局进行中，只在状态栏左侧以轻量模式徽章显示当前模式，旁边放一个小按钮 `切换模式 / 重开`（点击展开轻量选择或回到选模式页），直接省出 `42px` 并大幅减轻视觉噪音。
  2. **合并 `.cm-status` + `.cm-weather` + `.cm-pack` 为“紧凑双行指挥顶带”**（总高压缩至 `~74px`）：
     - 第一行（墨绿底主条，单行 `44px`）：左侧 `第 3/5 天 · 晨间派单桌` + 模式小标签；右侧并排展示 `💰 经费`、`★ 声望`、`💼 钱包` 与 `🎒 背包 0/4` 胶囊（悬停或点击展开道具列表）。
     - 第二行（轻便签条，`28px`）：仅在有天气/额外词条时显示紧凑单行风向提示（或直接嵌进「今日委托」卡片区标题栏右侧）。
  3. **压缩 `#hub-nav` 与子 Tab 的纵向留白**：子 Tab 改用轻量下划线式文字导航（`padding: 4px 10px`，不再套一层高框按钮），与 `#hub-nav` 区分主次，同时再释放 `~30px`。
  - **验收标准**：`1440×810` 下，晨间派单桌从顶栏到「盖章派单」按钮、以及现场实况舞台到 3 个危机按钮**全部一屏完整可见，无需滚动**。

### 2. [P0] 根治 3 处肉眼可见的“单字孤儿换行”排版事故
- **实测痛点**（在 `1440×810` 与 `390×844` 实机截图中均已确认）：
  1. **输出温度 3 个按钮全员切字**：`0.1 稳健对 / 齐`、`0.7 校园均 / 衡`、`1.6 放飞过 / 载`，3 个按钮全部把最后一个字挤到第二行！
  2. **部员卡双专长切字**：GPT、Gemini、Grok 卡片里的 `文采礼仪 / 逻辑省 / 钱`、`情报嘴替 / 脑洞才 / 艺` 全部出现单字掉行；且手机竖屏第 1 行因此导致 `Claude` 卡片比 `GPT / Gemini` 矮一截（`104px` vs `121px`）。
  3. **委托标题单字掉行**：如 `替广播站修补午间点歌栏目的三分钟冷 / 场`。
- **优化方案**：
  1. **温度按钮改为“上下双层分段卡”**：
     ```html
     <button class="cm-temp-btn" data-temp="0.7">
       <strong>0.7</strong>
       <small>校园均衡</small>
     </button>
     ```
     数字居中加粗（`1.15em tabular-nums`），中文标签 2~4 字设 `white-space: nowrap; font-size: 0.78em;`，并配主题色选中态（`0.1` 冷静湖蓝 `#2c6b78` / `0.7` 学园墨绿 `#183e38` / `1.6` 过载绯红 `#9e233a`）。
  2. **部员专长改为独立微标签（无 `/` 拼接）**：
     - 用 2 个极紧凑的无换行胶囊纵向/横向排布（如 `[文采礼仪]` `[逻辑省钱]`，`font-size: 0.72em; padding: 1px 5px; white-space: nowrap;`），高度严格对齐；
     - **核心玩法反馈联动**：当玩家选中某一桩委托时，若某部员拥有该委托要求的专长，其对应的专长微标签立刻亮**暖金高亮底**，卡片右上角点亮小徽标 **`✦ 匹配`**！告别肉眼比对文字。
  3. **标题平衡与手机等高**：给 `.cm-order strong` 增加 `text-wrap: balance;`；手机端 `.cm-team` 设 `align-items: stretch;`，`.cm-member` 设 `height: 100%;`，确保 3+2 Bento 网格每行卡片底边严丝合缝对齐。

### 4. [P1] 现场实况连线 (`.cm-stage` & `.cm-crisis`)：四类危机选项一眼分色
- **实测痛点**：当前 `cm-safe`（稳妥兜底）与 `cm-risk`（冒险整活）视觉几乎完全一样，都是平淡米白框；玩家需要逐字阅读下方小字才能区分哪张是稳妥、哪张是赌狗。
- **优化方案**：
  1. **危机策略卡片强语义着色**：
     - **稳妥兜底 (`cm-safe`)**：青绿左饰条 `#3a7a63` + 柔和浅青标题胶囊 `稳妥`；
     - **冒险整活 (`cm-risk`)**：琥珀橙左饰条 `#c8742a` + 浅橙底胶囊 `冒险`；
     - **角色/羁绊特解 (`cm-special`)**：鎏金双边 + 暖金微光底 + `✦ 专属特解` 烫金标（保持现行优秀高亮并增强对比）；
     - **1.6 过载 / 混沌整活 (`cm-overdrive / cm-chaos`)**：绯红紫边框 `#a13b67` + 淡粉底 + `⚡ 过载` 徽章。
  2. **数值标签药丸化**：把卡片底部一长串纯文本（`完成度 +50% · 风险 +18% · 透视成功率 76%`）拆成 2~3 个彩色小数字胶囊（`+50% 进度` 墨绿、`+18% 风险` 砖红、`风险归零` 翠绿），扫视速度提升 3 倍！
  3. **背包道具与配角外援改用“横向紧凑快捷栏”**：放在危机选项正下方作为一行带头像/图标的快捷支援胶囊，不占用过多垂直空间。

## 二、「404 放学后游乐角」与其余小游戏 UI 优化清单

### 1. [P0 实测 Bug 必修] Grok「午夜吃瓜木头人！」侧栏立绘完全不可见
- **实测根因**（`src/arcade.css` L60 & `assets/sprites/grok-1/smug.webp`）：
  - `grok-1` 系列立绘因左侧扛着巨型 X 道具斧，角色脸部重心偏右（`x ≈ 60%`），而 `.arc-announcer img` 统一写死 `height: 175%; width: 100%; object-fit: cover; object-position: center top;`。在 `203px` 宽的侧栏内强行放大裁切后，裁切窗口落偏导致 Grok 消失！
- **修复方案**：
  - 在 `arcade-room.js` 渲染 `.arc-announcer img`（以及 `.arc-host-figure img`）时写入 `data-actor` 或 CSS 变量 `--focus-x`（默认 `50%`，`grok` 设为 `63%`，`gpt` 设为 `52%`）；
  - 调整 `.arc-announcer img` 为 `height: 148%; top: 2%; object-fit: cover; object-position: var(--focus-x, 50%) top;`，并确保侧栏底部对白 `.arc-announcer p` 背景使用高不透明度 `#fffaeafc`（顺带修复 GPT 破折号游戏里裙摆透过文字的瑕疵）。

### 2. [P1] 全局修复「404 社团活动室」右侧边缘不对称留白
- **实测根因**（`src/game.css` L1075–1076）：
  - `#system-body` 启用了 `scrollbar-gutter: stable;` 与对称 `padding`，而 `#hub-nav` 和 `.dialog-head` 未预留滚动条槽位，导致 Windows 下所有活动室子页（委托、游乐角、Kimi 娱乐室）右边均比顶栏缩进 ~17–30px，视觉明显偏左不对称。
- **修复方案**：
  - 给 `#system-body` 使用 `scrollbar-gutter: stable;` 时，同步微调其 `padding-inline-end`（例如比左侧少 `8px`），或给 `#hub-nav` 与 `.dialog-head` 设置匹配的右内边距视觉对齐，使所有卡片右边线与顶栏按钮右边线精准垂直对齐！
