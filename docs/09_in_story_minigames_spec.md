# 《私立白箱学园：今天社团也没对齐！》剧情内互动小游戏操作性升级方案

> **设计核心**：在不破坏现有序章～第五章任何主线剧本与存档兼容性的前提下，将原先偏静态的剧情事件节点（`delete_panic`、`temp_tuner`、`cot_spinning`、`suspended_card`、`dispatch_board`）以及三大核心高光桥段（野炊熬咖喱、运动祭二人三足、文化祭后夜祭烟花）全面改造为**“10～20 秒轻操作、高反馈、零卡关”的真互动微游戏**，彻底消除纯点击阅读的疲劳感。

---

## 一、 全局交互设计铁律（商业级手感标准）

1. **短平快、高反馈**：每个剧情内小游戏控制在 **8～18 秒** 完成，紧密配合 `src/audio.js` 合成音效与屏幕微震、粒子闪光、立绘即时表情变化。
2. **绝不卡关 & 无障碍开关**：
   - 在【学园环境设置】新增偏好项 **`剧情互动小游戏`（`settings.minigames = true`）**；关闭后自动回退为原有简洁点击流程，兼顾操作党与躺平阅读党。
   - 小游戏失误时**绝不 Game Over**，而是触发 2 秒搞笑角色吐槽动画并提供 **【再来一次】** 与 **【直接过关看剧情】** 双按钮。
3. **全设备友好**：全部小游戏同时支持 **鼠标操作（点击/按住/拖拽）**、**键盘快捷键（`Space` / `←` `→` / `A` `D`）** 与 **移动端触屏点击**。
4. **无侵入式挂载**：前 5 项改造直接增强 `src/game.js` 中已有的 `panic()`、`tuner()`、`thinking()`、`showNotice()`、`dispatch()` 函数；第 6 项通过监听既有章节节点/标签钩子触发，**零剧本重写成本**。

## 二、 五大现有剧情组件的“真操作化”升级详案

### 2.1 升级一：【碎纸机拔河抢稿 + 贴星修复】（改造 `delete_panic` · 序章 / 第一章 / 第四章）
- **原版问题**：进度条死锁在 `89%`，点击一次即通关，缺乏紧张手速乐趣。
- **两段式实操机制**：
  - **阶段 A · 拔河拉锯（6～10 秒）**：
    - 碎纸进度条从 `62%` 起步，每帧自动以 **`+13% / 秒`** 的速度向 `100%` 推进，右侧碎纸机图标剧烈抖动并发出 `se_shredder_jam` 节奏咔哒声。
    - 玩家反复点击大按钮 **【✋ 拉回稿件！】** 或连按 **`Space`**，每次拉回 **`-10.5%`**（进度条回退时伴随角色气泡即时变脸：`不要拦我让我删光QAQ！` → `呜哇部长力气好大！` → `快扯出来了！`）。
    - 将进度拉回 `0%` 立即进入阶段 B！（若放任涨到 `100%`，播放搞笑纸屑飞舞动画并提供【拿胶带粘好重抢】按钮）。
  - **阶段 B · 精准贴星修复（2～3 秒）**：
    - 抢回的迎新海报/立体海豚贺卡铺开在弹窗中央，错别字或歪掉的折角处标有闪烁金色虚线靶圈。
    - 玩家点击（或拖动）右下角闪亮的 **【✦ 四芒星贴纸】** 贴在靶圈内，“叮！”地绽放满屏金星特效，直接弹出 `✨ 顺毛成功！猫猫已恢复运行` 并续播对话！

### 2.2 升级二：【动态心音示波器 · 真实温度调谐仪】（改造 `temp_tuner` · 第一至五章共 10 处）
- **原版问题**：本质是 3 档离散单选按钮，缺乏调谐手感与章节差异化。
- **动态共振微操机制**：
  - 上方新增一块 **`Canvas` 实时双轨示波器**：
    - **虚线白波（目标共鸣频率）**：稳定舒缓的正弦波；
    - **实线彩波（角色当前心音）**：随指针刻度 `0.00 ～ 2.00` 实时改变振幅、频率与颜色（低温 `<0.4` 冰蓝平直线、黄金区 `0.62～0.88` 温暖金波、高温 `>1.3` 狂暴紫红锯齿波！）。
  - **动态干扰物理（按剧情氛围赋予趣味微操）**：
    - 滑块不再死板静止，而是带有**微弱的环境漂移力**——例如第二章停电夜（`actor: grok`）每次闪雷指针会向右抖动偏移 `+0.18`；第四章发烧夜（`actor: deepseek`）指针会缓慢向高温端爬升模拟发烧过热！
  - **玩家操作**：
    - 玩家用鼠标拖动（或 `←` / `→` 方向键微调）黄铜指针，将两道波形对齐至黄金区间（示波器泛起金色光环），按住或点击 **【⚡ 锁定共鸣】** 即可命中 `中温 T = 0.7` 正解！
    - **完美保留主动玩梗自由**：如果玩家故意把指针拖进低温蓝区（`< 0.40`）或高温红区（`> 1.35`）按下锁定，依然会精准跳转至对应的 `低温冷场` 或 `高温发癫` 搞笑支线（满足玩家收集《算力烧烤大师》成就的乐趣！）。

### 2.3 升级三：【DeepSeek 思维链剪枝小游戏】（改造 `cot_spinning` · 序章 / 第一章 / 第三章）
- **原版问题**：静态折叠框，只能点开看字，没有帮她理清思绪的互动感。
- **「杂念气泡剪枝」轻操作机制（8～12 秒）**：
  - 弹窗上方为旋转呆毛进度环（初始思维纯度 `40%`），中间是漂浮气泡区，动态飘过 **5～6 个圆润气泡**：
    - **🔴 跑偏杂念气泡（3 个，微红虚线框，持续抖动）**：例如 `先 sleep 十分钟吧`、`难道要逼鲸鱼学猫叫喵？！`、`偷偷外包给隔壁桌？`、`算算食堂打折券……`。
    - **🔵 核心线索气泡（2～3 个，清澈海蓝框）**：例如 `留住新部长最关键`、`锅巴贿赂方案可行`、`麻婆豆腐单独下饭绝佳`。
  - **玩家操作**：快速点击戳破全部 **3 个红色跑偏杂念气泡**！每戳破一个伴随清脆水泡破裂音效 + 思维纯度 `+20%` + DeepSeek 小声反馈（`啊，差点又走神了！`）；若误点蓝色有效线索则只轻轻弹开并提示 `这条推理很有用，别删掉呀！`。
  - 纯度满 `100%` 后，呆毛“叮”地定格，自动解锁高亮的【听听推演结果 →】（同时仍保留可展开的完整万字思维链原文）。

### 2.4 升级四：【手撕/反盖章破除 Claude 停权黄牌】（改造 `suspended_card` · 序章 / 第一章 / 第四章 / 第五章）
- **原版问题**：自动弹出自动缩小，纯视觉装饰。
- **趣味互动微改造**：
  - 黄牌盖章弹出后，右下角带有一枚微微卷起的动态折角与两个迷你快捷交互：
    1. **点击或拖拽卷角“撕下黄牌”**：撕掉后在原本压住的位置短暂飘出一句 Claude 偷偷写在背面的娇羞小字（如 `……轻点撕，手劲小一点我就不计较了`）。
    2. **点击【盖上 404 部长豁免红章】**：啪地一声在 `SUSPENDED` 上斜压一枚鲜红圆印 `【部长特批 · 撤销停权】`，音效与视觉反差感拉满！
  - *(若玩家不理会直接点对话继续，卡片仍按原逻辑自动淡出，绝不拖慢阅读节奏！)*

### 2.5 升级五：【双人派单板 · 社团支援道具槽】（改造 `dispatch_board` · 序章 / 第一至三章）
- **原版问题**：预设三组卡片直接单选，战术策略感稍弱。
- **轻量策略增强**：
  - 保留原有的 3 组黄金搭档卡片，在底部新增一排 **【顺手塞一件 404 社团支援道具（3 选 1）】**：
    - 通用/按章道具示例：`🍚 应急锅巴包`（搭配 DeepSeek 触发「碳水充能」）、`🦀 小螃蟹护身符`（搭配 Claude 触发「防限流护盾」）、`⭐ 备用金星贴纸`（搭配 Gemini 触发「防删稿安心」）、`🥤 冰镇青柠汽水`（搭配 Grok 触发「嘴硬降温」）、`🫖 桂花白茶罐`（搭配 GPT 触发「免破折号稳态」）。
  - 选中搭档与道具后，派单板右侧实时亮起一行俏皮的 **【搭档化学反应预测】**（如 `⚡ 触发共鸣：Claude 带着小螃蟹，审稿抗压 +100%！`），盖章出击时弹出 1.5 秒专属出发气泡，增强“作为部长亲自配装派单”的成就感！

## 三、 三大高光章节专属轻动作微游戏（无侵入钩子触发）

以下 3 个仅需 **12～18 秒** 的轻动作微游戏，通过监听剧本既有关键节点触发（零剧本改动，且受 `settings.minigames` 统一开关控制）：

### 3.1 第二章 · 合宿野炊【大锅咖喱火候搅拌挑战】
- **触发时机**：第二章第二幕在任意厨房路线中选完灵魂秘料之后、切入第三幕停电夜之前。
- **操作玩法（极简版《星露谷》平衡槽 · 约 10 秒）**：
  - 屏幕上出现一只咕嘟冒泡的咖喱大铁锅与一根纵向/横向**「火候平衡槽」**，中间有宽敞的金色 **「香浓完美区」**（占总长 32%）。
  - 锅内火候浮标会受重力缓慢下落；玩家**按住鼠标左键或 `Space` 键**即顺时针搅拌加大火力让浮标上升，松开则缓慢回落。
  - 将浮标保持在金色区域内累计满 **`3.5 秒`**，上方美味度进度条满格，伴随金光特效弹出 **「✨ 绝品海风合宿咖喱大成功！（全员满足度 MAX）」**！

### 3.2 第三章 · 春季运动祭【二人三足节奏冲刺】
- **触发时机**：第三章第二幕完成二人三足场边口令抉择后，呈现冲刺撞线瞬间！
- **操作玩法（极简双键左右交替节拍 · 约 12 秒）**：
  - 操场前景出现可爱的双人跑道进度条，下方并排摆放 **`[◀ 左脚 (A / ←)]`** 与 **`[右脚 (D / →) ▶]`** 两枚大按钮。
  - 伴随 `audio.js` 轻快的 `120 BPM` 哨声与鼓点，左右按钮交替亮起金色节奏光环！玩家依次交替点击（或按键盘 `A`/`D`、`←`/`→`）累计完成 **10 步同步冲刺**，每次命中双人立绘同步在操场上轻快跃动加速冲向终点线！
  - 连击达到 8 次以上触发 **「⚡ 完美同步 · 破校纪录冲线！」** 专属彩带特效！

### 3.3 第五章 · 后夜祭【亲手点亮星海告白烟花】
- **触发时机**：第五章任意女主终章中，即将从普通对话切换进入全屏告白事件 CG（`cg_confession_*`）之前的 8 秒神级过渡！
- **操作玩法（极富仪式感的星夜交互 · 约 8 秒）**：
  - 画面化作静谧深邃的星海夜空，5 颗拖着细微金尾的未引爆烟花光球缓缓从海平线升起（速度舒缓、判定范围大，绝不紧张卡手）。
  - 玩家亲手点击空中的光球，每点亮一颗便在点击位置用 Canvas 绽放出一朵对应五位女主主题色的绚丽烟花粒子（霜紫、琥珀橘、星粉金、绯红、海蓝），伴随清脆烟花绽放音效！
  - 当玩家亲手引爆第 5 朵位于画面正中央的超级金色大烟花时，璀璨光芒铺满全屏，顺势**无缝淡入该女主的专属全屏告白事件 CG（`cg_confession_*`）**，将整部游戏的情感仪式感推向顶点！
